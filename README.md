# Machine Learning Data Preprocessing Project

This project was completed as part of my Machine Learning Internship at Codveda Technology.

## Project Objective
The goal of this project is to preprocess a raw stock prices dataset and make it ready for machine learning models.

## Tasks Performed
- Loaded and analyzed the dataset
- Checked missing values
- Handled missing data
- Encoded categorical variables
- Standardized numerical features
- Split dataset into training and testing sets
- Saved processed dataset

## Technologies Used
- Python
- pandas
- NumPy
- scikit-learn
- Jupyter Notebook

## Files Included
- Data_Preprocessing_Task.ipynb
- processed_stock_data.csv
- README.md

## Learning Outcomes
Through this project, I learned:
- Data cleaning techniques
- Feature preprocessing
- Handling missing values
- Feature scaling
- Train-test splitting
